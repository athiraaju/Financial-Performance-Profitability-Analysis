 # Financial Performance & Profitability Analysis

## 📊 Project Overview

This project focuses on analyzing financial data using Microsoft Power BI to understand business performance through sales, profit, profit margin, and Cost of Goods Sold (COGS).

The dashboard provides interactive insights into financial performance across different products, countries, and business segments.

## 🎯 Project Objectives

- Analyze total sales and total profit.
- Understand profit margin and business profitability.
- Examine Cost of Goods Sold (COGS).
- Compare financial performance across products, countries, and segments.
- Identify trends and support data-driven business decisions.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 📁 Dataset

**Dataset:** Financial Sample.xlsx

The dataset contains financial information such as sales, profit, COGS, products, countries, segments, and dates.

## 📈 Key Performance Indicators (KPIs)

- **Total Sales:** Measures overall sales revenue.
- **Total Profit:** Measures the profit generated.
- **Profit Margin:** Shows profitability as a percentage.
- **Units Sold:** Measures the total quantity sold.
- **Total COGS:** Measures the cost of goods sold.
